Lisbon 27-30 Aug

以 Alvito / Alcantara 做基地，將 Lisbon 拆成 Belém、Baixa/Chiado、Alfama/Castelo/Graca 同住宿附近四組。地圖用 Leaflet + OpenStreetMap；所有景點卡都係靜態 HTML，所以就算地圖 script 載入失敗，內容都仍然會完整顯示。

Public GitHub Pages safety: 住宿只寫 Alvito / Alcantara 大區，不放完整門牌地址。

最重要決定

  • 必去Jerónimos、Belém 河邊、Praça do Comércio、Carmo、Castelo、Alfama miradouros
  • 可 skipSanta Justa Lift、Pink Street、專登排長龍坐完整 Tram 28
  • 買飛Jerónimos / Belém Tower 入內要早買；Castle 建議 online；其他多數 walk-in
  • 策略先搭車上山，再一路行落山，慳腳力

地形概念

Lisbon 唔係平地城市。南面係 Tagus 河，Baixa 係低地，Chiado / Bairro Alto 向西上山，Alfama / Castelo / Graca 向東上山。住 Alvito / Alcantara 即係偏西、近 Belém，但回家最後一段多數會上斜。

Belém / Alcantara

河邊較平，適合排同一日慢慢行。你住得近，27 號到步後可以輕鬆去 LX Factory 或 MAAT。

Baixa / Chiado

市中心低地接上山區。Praça do Comércio、Rua Augusta、Rossio、Carmo、Chiado 可以串成一條自然 walking route。

Alfama / Castelo / Graca

最有 Lisbon 感，但多斜路石路。建議早上先去 Castle 或高位，再一路行落 Alfama。

交通點用

Lisbon 交通由 Metro、tram、bus、train、ferry 組成。遊客最常用係 contactless bank card / Viva Viagem / Navegante occasional card / 24h pass。票價同 pass 規則會變，正式買之前睇一次官方資料。

上車付款

Metro 入閘 tap；bus / tram 通常上車 tap。迫 tram 要小心手機同銀包，特別係 Tram 28 同熱門景點站。

幾時買 24h pass

如果同一日會多次搭 Metro / bus / tram，24h pass 先容易抵。只搭一兩程就用單程或 zapping 比較簡單。

你住 Alvito 的路線

西面玩 Belém / Alcantara 很順。去市中心多數先落 Alcantara / Cais do Sodré，再接 tram、train 或 Metro。

葡萄牙航海時代、Manueline 建築、河邊 monument 集中地。適合 28 號朝早第一批去 Jerónimos，再沿河行去 Belém Tower。

Lisbon 最代表性的 Manueline 建築之一。最值得看的是 cloister；教堂外觀和部分區域即使不入付費區也很有份量。

Belém Tower

Lisbon icon。外觀、河邊位置和拍照價值很高；入內空間較小，要不要買 timed ticket 視乎你對 fortress 有幾大興趣。

地址Av. Brasília, Belém

Lisbon historic centre。由 Praça do Comércio 入城，穿過 Rua Augusta，到 Rossio，再上 Carmo / Chiado，最後可以去 São Pedro de Alcantara 看黃昏。

3. Alfama / Castelo / Graca

最有 Lisbon feel 的區域：紅瓦屋頂、窄巷、斜坡、觀景台。最舒服做法係先搭車到高位，再慢慢向下走。

先上 Castle 落山去 Alfama 避開中午 Tram 28

Ajuda National Palace

保存完整的 19 世紀皇宮 interiors。因為靠近住宿，很適合 30 號離開前排半日，前提是 FlixBus 時間許可。

地址Largo da Ajuda
買飛通常不用搶，仍建議出發前查開放
評價內部豐富；不是第一次 Lisbon 絕對必去

27-30 Aug 骨架

這不是逐分鐘行程，而是按地理和體力最合理的框架。30 號要按 FlixBus 站名和出發時間再收窄。

27 Thu｜到步

Check-in 後留在 Alcantara：LX Factory 食飯 / 逛逛，精神好就加 MAAT 河邊。

28 Fri｜Belém + Centre

早上 Jerónimos，之後 Pastéis、Padrão、Belém Tower，下午接 Praça do Comércio、Baixa、Carmo、Chiado。

29 Sat｜Castle + Alfama

早上先上 São Jorge Castle，再落 Portas do Sol、Santa Luzia、Alfama、Sé。星期六可看 Feira da Ladra。

30 Sun｜近住宿半日

FlixBus 下午才走的話，可選 Ajuda Palace / 近河邊輕鬆 brunch。不要排太遠的景點。

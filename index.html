01 · 全市總覽

Lisbon 河岸由 Belém → Alcântara → Cais do Sodré → Baixa 相對平；Chiado、Castelo、Alfama、Graça 就係向山上走。你住喺 Alcântara 上面，所以西面景點近，但返 apartment 通常要上斜。

Lisbon 全市景點概念地圖撳圖開 Google Maps
你最應該記住：Belém / Alcântara 可以當一個西面世界；Baixa/Chiado 係中段；Castelo/Alfama/Graça 係東面山丘。東面最好搭 737 上 Castelo，然後一路行落山。

02 · 交通

主要用 CARRIS bus/tram + Metro。Metro 入閘同出閘都要用同一張卡/同一部裝置；bus/tram 通常上車拍卡一次，落車唔使拍。

03 · Pass / 買飛

你今次最重要係保障高需求景點嘅 slot，而唔係先買一張 city card 再算。

優先買

Jerónimos：旺季 timed slot，建議先鎖。
Belém Tower：只係你好想入內先鎖。
São Jorge Castle：online 買可慳售票隊。

Lisboa Card

理論上景點多就容易回本，但 Jerónimos / Belém Tower 嘅 card-holder reservation 有 allocation 問題。

你今次：Jerónimos 如果係必去，我會直接買 timed ticket，唔建議為咗理論上免費而冒 slot risk。

05 · 使用說明

呢個版本係為 iPhone 內置 HTML 預覽器而設。地圖係 OpenStreetMap static preview；撳圖或 Google Maps button 就會跳去真正 live map。相片來自 Wikimedia Commons，撳圖可以睇原檔與授權資料。

如果你仍然見到某張 map / photo 空白：

嗰樣只代表該外部圖片 host 被當時網絡/預覽器擋咗；景點卡內容本身仍會喺度。用「Google Maps」或「相片來源」按鈕可以直接打開。呢版唔會再因為一個 script fail 而令成個 cluster 消失。
